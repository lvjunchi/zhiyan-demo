# UI-Z2 总览标题、卡车、数字与当前进度

## 用户要求与实现

本轮只处理用户给定的四项（会议第2/5/7/8项），关联AC-19/20/21受控展示与导航范围，未启动其余会议任务。

- 参考用户附件的工业蓝色线稿方向，以本地SVG重新绘制前侧视卡车、车架、车轮和透视网格；替换UI-Z1平面侧视图。不是实车/CAD证据，无外部图片或运行时网络依赖。
- 完整平台名称由深色工具栏移至页面标题右侧，项目总览桌面同行；其他模块统一，手机换行，工具栏保留面包屑和备份恢复。
- 需求数字蓝色、覆盖青绿、执行根据现有结果用绿/琥珀/红、冲突有阻断用红无阻断用绿，未知保持灰；参数数字青蓝，资源/智能体数字加深。数值和后端判定不变；颜色不用于新增审核或门禁规则。
- 总览项目卡片顶部显示“当前进度”、已有成果所处阶段、现有状态和待澄清/阻断数量，上方五阶段流程唯一aria-current=step高亮。继续处理进入该成果模块，问题按钮进入协议澄清。
- overviewProgress.ts只根据API已保存成果定位导航：无需求→协议导入、有需求→需求确认、变型/设计成果→第3阶段、方案/样件→第4阶段、已有材料→第5阶段；草稿/待更新和阻断不隐去。这是成果位置，不是执行running状态，也不是阶段通过/前序问题关闭判定。后端仍是审核/符合性/门禁唯一权威。
