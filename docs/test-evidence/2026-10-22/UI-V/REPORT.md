# UI-V：材料详情与准备工作分离

关联O13、AC-16/17/18/20/21；依赖UI-U材料查看、既有门禁与审批API。用户确认列表“查看”和下方完整详情重复后，授权精简主页面。

## 实现与边界

主页面保留材料列表/查看/下载，以及“当前材料准备”：最新包编号、状态、生成/冻结时间、通过/阻断/提示数量、可操作待办和满足条件后的人工批准。移除重复的预览按钮、完整门禁表、长哈希、错误码大段汇总、第二个下载按钮及文件清单。对应内容统一在既有宽弹窗查看，补充提示也在弹窗展示。

待办不隐藏阻断：MaterialBlockers无导航回调时仍展示原因；可定位项使用简短“前往处理”，可访问名称保留完整原因。对象ID/revision仍按原契约传给导航，界面保留待核对版本。未知导航明确提示缺少关联信息，不补造对象链接。

审批仍只在ready_to_submit且非旧门禁时出现，使用当前包的实际snapshot_hash；历史弹窗不切换准备区/审批对象。批准前提示从列表核对快照，未新增自动批准或替用户确认。生成后快照不随修改更新、旧版门禁、草稿导出和历史保留规则不变。
