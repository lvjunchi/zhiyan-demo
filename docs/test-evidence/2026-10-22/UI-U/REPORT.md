# UI-U：材料查看反馈与历史列表整理

关联O13、AC-16/17/18/20/21；依赖既有材料API和DetailOverlay。

问题复核：“查看”原先仅调用GET后替换列表下方的detail，没有滚动、弹窗或明确反馈；查看同一包尤似无响应。现改为立即打开宽幅原生dialog，展示读取状态、错误/重试、材料编号、状态/模式、快照及ZIP哈希、门禁和文件清单。历史查看使用独立preview状态，不切换当前材料的门禁待办或审批对象；关闭/项目切换后忽略过期读取结果，Esc关闭返回原按钮。

用户询问“这些可以删除吗”存在记录/入口两种含义，本次不执行不可逆数据删除：默认只显示最新包，旧包通过“展开历史材料包（N）”查看/下载；这是列表整理，未实现删除API，也未删除/修改已有材料、审核或快照。后续若明确要求物理清理，需另定范围和保留规则，不能把收起宣称删除。
