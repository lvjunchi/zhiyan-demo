## 故障注入与“混沌测试”的实际范围

本轮做的是可重复、确定性的本地故障注入，不是生产级混沌工程验证。全部使用临时数据库/预览副本；没有填满真实磁盘、断开用户网络或杀死用户服务。

| 场景 | 注入位置 | 实际断言 |
| --- | --- | --- |
| 下游写入后抛错 | 用例失效、设计文档失效函数 | 整库快照哈希与故障前相同，源/派生/审核/依赖没有部分提交 |
| 零件审计失败 | part_decision.stale | 源、派生与零件状态全部回滚 |
| 源/派生审计失败 | requirement audit | 同一变更事务回滚，旧确认保留 |
| 数据库锁竞争 | 独立连接持有 BEGIN IMMEDIATE | 返回 503 PERSISTENCE_UNAVAILABLE；解锁后整库哈希不变 |
| 相同 revision 并发修订 | 两个线程/实际 API | 一个 200，一个 409；派生值只与胜出版本一致 |
| 恢复写入失败模拟 | 激活恢复指针前抛 OSError | 返回明确失败，当前数据不切换，服务重启仍是原数据 |
| 损坏/改结构/非法数值备份 | SHA、SQLite schema、Infinity、归档正文/样件/材料快照/ZIP 哈希 | 返回 422，当前数据不变 |
| 校验后当前数据变化 | 恢复 expected_state_hash | 返回 409，拒绝覆盖期间新增内容 |
| 浏览器接口断连 | 拦截总览请求 | 显示错误，不生成假指标；解除后可重试 |
| 浏览器保存 503 | 拦截修订请求 | 显示“未保存”，表格仍为原值；后端哈希不变 |

故障基础场景在本轮全量回归中重跑；新增工程版本与损坏快照拒绝、旧库迁移、并发导出证据在 docs/test-evidence/2026-10-19/VER-01/，旧 UI-G 输出仅作历史。未执行：长期高负载、分布式网络分区、操作系统级磁盘故障、进程强杀恢复和真实台架/模型验证；不将上述结果称作生产可靠性认证。

当前结果和后续范围见[任务与待办](TASKS.md#后续待办)。维护备份仅支持匹配当前数据库结构；旧备份不静默迁移或覆盖。
