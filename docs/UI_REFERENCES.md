# UI-G 界面借鉴记录

用户明确要求查找开源界面学习。本轮仅请求公开项目页面；项目材料、PDF、数据库和代码没有上传到外部服务。

| 官方项目 / 页面 | 查阅与借鉴 | 在本系统中的落点 |
| --- | --- | --- |
| [Ant Design Pro](https://github.com/ant-design/ant-design-pro) | 企业工作区的页面容器、列表/表单/详情分层和连贯导航 | ModuleWorkspace 的输入依据—工程工作—输出成果、相关模块入口、统一标题层级 |
| [Tabler 官方演示](https://preview.tabler.io/) / [源项目](https://github.com/tabler/tabler) | 紧凑卡片、表格表头、轻量状态标识、独立操作区 | 工业蓝灰色表格、单据计数、表单操作栏、固定底部产品说明、备份与恢复复核面板 |
| [FlowFuse Dashboard](https://github.com/FlowFuse/node-red-dashboard) / [官方文档](https://dashboard.flowfuse.com/) | 面向可视化工作台的分组、页面和组件组织 | 各模块沿输入/工作/成果组织，保持总览与详细工作区一致的层级 |

实现为仓库内 React/TS/CSS，未下载或粘贴整套开源模板、未新增运行时框架、未引入在线图标/字体/远程资源。不宣称上述项目提供了本系统的业务判定，也不把模板中的账号、通知、云连接等模块当成已实现能力。

检索时亦看到其他工业看板项目，但最终采用上述三个公开项目作为界面组织参考；正式来源以链接到的官方项目/演示为准，不依据转载截图宣称能力或许可证。
